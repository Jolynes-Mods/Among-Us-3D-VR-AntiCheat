Security Policy

Security Maintainer

Security Maintainer: Jolyne
Role: Security Maintainer

I am responsible for the security of this project, including vulnerability assessment, security improvements, reviewing reported vulnerabilities, and maintaining defensive protections.

Supported Versions

Security updates are provided for the latest actively maintained version of this project.

Version	Supported
Latest	Yes
Older versions	No

Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than publicly disclosing it.

Please include:

* A description of the vulnerability.
* Steps to reproduce the issue.
* Potential security impact.
* Any relevant logs, screenshots, or proof of concept.

Please allow reasonable time for the issue to be investigated and addressed before publicly disclosing it.

Security Practices

This project aims to maintain strong security through:

* Reviewing potentially exploitable code.
* Validating network communication and untrusted data.
* Preventing unauthorized modifications and tampering.
* Investigating vulnerabilities and implementing appropriate fixes.
* Minimizing unnecessary trust in client-side information.

Responsible Disclosure

Security reports are taken seriously. Confirmed vulnerabilities will be investigated and addressed where appropriate.

Researchers who responsibly disclose vulnerabilities may receive acknowledgment, with their permission.
